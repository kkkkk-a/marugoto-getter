※任意
📋 各サイトのCookie値（セッションキー）の取得手順（約30秒）:
  1. ブラウザで対象サイト（Pixiv、X/Twitter等）にログインします。
  2. キーボードの F12 キーを押します。（Macは Option + Cmd + I）
  3. 上のタブ 「Application」 → 左メニュー 「Cookies」 → 対象ドメインを選択します。
  4. 以下のCookie名をコピーして貼り付けます：
    • Pixiv (R-18・限定作品用): PHPSESSID の値
    • Twitter / X (センシティブ・鍵垢用): auth_token の値
🔒 安全性: CookieはブラウザのLocalStorageに保存され、スクレイピング実行時のみバックエンドサーバーへ安全に送信されます（第三者への送信・漏洩はありません）。
🔄 更新タイミング: 基本的に長期間有効ですが、ブラウザ側でログアウトした際やパスワード変更時は再度貼り直してください。
